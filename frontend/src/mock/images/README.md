# Images du portfolio

Remplacez ces fichiers par vos vraies images (en gardant les mêmes noms) :

| Fichier | Rôle |
|---|---|
| `photo.png` | Photo de profil (section « A propos ») |
| `logo.png` | Logo / favicon dynamique |
| `hero.png` | Texture de l'objet 3D de l'accueil |
| `hero-background.png` | Fond de la scène d'accueil |
| `project-1.png` … `project-6.png` | Captures des 6 projets |
| `tech-*.png` | Logos des technologies (cubes 3D) |
| `testimonial-1..3.png` | Photos des témoignages |

## Pour ajouter / renommer un projet ou une techno

Mettez à jour `src/mock/data.ts` en conséquence :
- ajoutez le fichier dans ce dossier,
- importez-le en haut du fichier,
- ajoutez/éditez l'entrée dans `projects` ou `technologies` en le référençant.
